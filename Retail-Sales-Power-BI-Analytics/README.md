# Retail Sales Analytics

Interactive Power BI dashboard for analyzing retail sales performance and business insights.

## Project Overview

This project analyzes retail sales data using Power BI to understand sales, profit, orders, quantity, product performance, customer insights, and salesperson performance.

## Dashboard Pages

- Retail Sales Analytics
- Product Analysis
- Customer & Salesperson Analysis
- Transaction Analysis

## Key Metrics

- Total Sales
- Total Cost
- Total Profit
- Total Quantity
- Total Orders

## Key Features

- Power Query
- DAX
- Data Modeling
- Interactive Slicers
- Data Visualization
- Dashboard Development

## Technologies Used

- Microsoft Power BI
- Power Query
- DAX
