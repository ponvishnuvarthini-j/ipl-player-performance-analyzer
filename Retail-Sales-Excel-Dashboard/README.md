# Retail Sales Dashboard

Interactive Excel dashboard for analyzing retail sales performance and business trends.

## Project Overview

This project uses Excel to analyze retail sales data and present key business metrics through an interactive dashboard.

## Key Analysis Areas

- Sales performance analysis
- Profit analysis
- Order analysis
- Product performance
- Salesperson performance
- Business trend analysis

## Dashboard Highlights

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Maximum Sale
- Minimum Sale
- Best Selling Product
- Best Salesperson

## Excel Features Used

- PivotTables
- PivotCharts
- KPI views
- Interactive slicers
- Data analysis and visualization
